# Мёртвый штиль (Dead Calm)

Сюжетный noir-детектив о расследовании дела №001 «Последний рейс» в портовом городе Блэкфорд.

## Требования

- Node.js 22 или новее — для запуска регрессионных тестов.
- Современный браузер с поддержкой ES modules, localStorage и Service Worker.

## Запуск игры

Проект является статическим веб-приложением. Откройте его через локальный HTTP-сервер из корня репозитория, а не через `file://`.

Например:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

Tailwind CSS сейчас подключается с внешнего CDN, поэтому для полного оформления при первом запуске требуется интернет-соединение. Service Worker кеширует same-origin ресурсы и две авторские SVG-иконки приложения; полноценный offline-режим не заявляется до ручной проверки браузера.

## Тесты

```bash
npm test
```

CI использует Node.js 22 и запускает ту же команду при push в `main` и при открытии pull request.

## Структура

- `index.html` — точка входа.
- `src/js/core/` — запуск приложения, маршрутизация, состояние, сохранения и события.
- `src/js/scenes/` — игровые сцены.
- `src/js/systems/` — игровые и сюжетные системы.
- `src/data/` — данные персонажей, улик, диалогов, локаций и событий.
- `src/assets/` — графические ресурсы.
- `src/css/` — стили и визуальное направление.
- `tests/` — регрессионные тесты.
- `docs/` — спецификация, канон, сюжет и производственные документы.
