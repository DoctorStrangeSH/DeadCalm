## О проекте

**«Мёртвый штиль» (Dead Calm)** — самостоятельный сюжетный детективный триллер в вымышленном портовом городе Блэкфорд.

Игрок — детектив Джон Риверс. После убийства судьи Гаррисона расследование приводит его к старому делу «Каллиопа», событиям двадцатилетней давности и людям, чьи версии прошлого не всегда совпадают.

Это не бесконечный генератор дел и не набор разрозненных головоломок. Цель проекта — выпустить одну цельную, авторскую и полностью проходимую историю с честной доказательной цепочкой, значимыми разговорами и последствиями решений.

**Статус: в разработке.** Целевая версия — **1.0.0**. Автоматические тесты не считаются заменой полноценного прохождения игры.

## Что делает игру особенной

- **Детектив без всеведения.** Улики подтверждают конкретные обстоятельства, а не автоматически раскрывают всю правду.
- **Персонажи со своей памятью.** Важны источники сведений, отношения, обещания, личные мотивы и поступки игрока.
- **Ненадёжные показания.** Слухи и пересказы могут терять детали, искажаться и противоречить другим источникам.
- **Последствия разговоров.** Реакции и доступность помощи зависят от сохранённого контекста, а не только от выбранной реплики.
- **Физические мини-игры.** Ремонт механизма, настройка аналогового радио и восстановление киноплёнки встроены в расследование.
- **Авторский визуальный стиль.** Дождливый портовый город, живописные окружения, сдержанная типографика и атмосферный noir.

## Быстрый запуск

### Требования

- Node.js **22 или новее** — для запуска тестов.
- Современный браузер с поддержкой ES modules, localStorage и Service Worker.
- Python 3 или любой другой локальный HTTP-сервер — для запуска игры.

### Запустить игру

Из корня репозитория:

    python -m http.server 8000

Откройте в браузере:

    http://localhost:8000

Не открывайте index.html напрямую через file://: приложению нужен HTTP-контекст.

> **Сеть:** Tailwind CSS загружается с внешнего CDN. Поэтому для полного оформления при первом запуске требуется интернет. Полноценный offline-режим пока не заявлен.

### Запустить тесты

Установка npm-зависимостей не требуется: тесты используют встроенный Node.js Test Runner.

    npm test

CI запускает ту же команду на Node.js 22 при push в main, открытии pull request и вручную через GitHub Actions.

## Правила разработки

1. Перед изменением игрового объёма сверяйтесь с [Master Spec](docs/MASTER_GAME_SPEC_RU.md).
2. Не добавляйте новые механики только потому, что они интересны: сначала завершайте и связывайте утверждённый маршрут.
3. Не меняйте сюжетный канон без фиксации решения в соответствующих документах.
4. Не заменяйте утверждённые портреты и их эмоциональные варианты без прямого разрешения владельца.
5. Не удаляйте файлы по названию или возрасту: сначала проверяйте импорты, маршруты, ссылки, кеш Service Worker и тесты.
6. После изменений запускайте npm test; ручное прохождение и проверка браузера отмечаются отдельно.
7. Не сливайте рабочие изменения в main до проверки diff и прохождения CI.

Подробные правила для AI-агентов и разработчиков находятся в [AGENTS.md](AGENTS.md).
